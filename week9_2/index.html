02 — THE WORK

Seven fixes, one clearer experience.

The specific changes behind the score improvements.

01

Give every page a proper title

DOCUMENT TITLE

Where 11 pages across Week 2 and Week 3

Without a descriptive title, browser tabs and assistive technology offer little context about the page. I added a specific <title> to each document.

View the change ＋
02

Turn fragments into complete documents

HTML HAS LANG

Where week2/ex2, ex3, ex4 and ex7

These pages had no document shell, language declaration, or head section. I added a complete HTML structure with lang="en", metadata, a title, and a main landmark.

View the change ＋
03

Make colour labels readable

COLOR CONTRAST

Where week3/ex3.html

White labels on the colour swatches measured between 2.14:1 and 3.76:1, below the 4.5:1 target for normal text. Changing the labels to black improved contrast across the swatches.

View the change ＋
04

Improve contrast in the footer

COLOR CONTRAST

Where week3/ex8.html

The shared footer text colour, #587078, reached only 2.78:1 against the dark background. A page-level override makes the text lighter and easier to read.

View the change ＋
05

Make navigation easier to tap

TARGET SIZE

Where week2/ex3.html

The menu links were only 17px tall. I added vertical padding and a 24px minimum height so the targets are easier to activate.

View the change ＋
06

Add a main landmark to exercise pages

LANDMARK ONE MAIN

Where 22 Week 2 and Week 3 exercise pages

Wrapping the primary page content in <main> gives screen-reader users a direct route to the page's main content.

View the change ＋
07

Let keyboard users skip navigation

BYPASS BLOCKS

Where Pages with a main landmark, via site-nav.js

A skip link now appears when focused, letting keyboard users bypass repeated navigation and jump directly to the main content.

View the change ＋
