# Week 11 — React components, props, state, and events

This React app includes the Week 11_1 components-and-props lesson and a
Week 11_2 state-and-events lesson. Week 11_2 demonstrates counters, controlled
inputs, list updates, and conditional rendering. Both pages use the portfolio's
shared visual design. The production build is written to `dist/`; the small
`index.html` in this folder forwards GitHub Pages visitors to Week 11_1.

The project gallery is shared with the repository's root `portfolio.html`.
Builds output the gallery widget alongside the coursework app.

```sh
npm install
npm run dev
npm run build
```
