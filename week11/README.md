# Week 11 — Mahmudjon Okhunov · React components, props, state, and events

This React app includes the Week 11_1 components-and-props lesson and a
Week 11_2 state-and-events lesson. Week 11_2 demonstrates counters, controlled
inputs, list updates, and conditional rendering. The pages use a custom
indigo-and-lime design and display text-only profile cards. The production
build is written to `dist/`; the small `index.html` in this folder forwards
GitHub Pages visitors to Week 11_1.

The project gallery highlights Mahmudjon's coursework projects.

```sh
npm install
npm run dev
npm run build
```
